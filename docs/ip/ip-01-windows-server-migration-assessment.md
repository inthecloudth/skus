# IP-01: Windows Server 2016 Migration Assessment & Roadmap

> **Type:** Repeatable Service Package  
> **Delivery Unit:** 1 Assessment สำหรับกลุ่ม Server/Workloads ที่กำหนด  
> **Baseline Effort:** 6 Man-days

## Objective

ประเมินความพร้อมและจัดทำแผนย้าย Windows Server 2016 ไปยัง Windows Server 2022/2025

## Scope

สำรวจ Server, Application และ Dependency ตามรายการที่ตกลง ประเมินความเสี่ยงและความซับซ้อน พร้อมกำหนด Target Baseline, Migration Approach และ Migration Waves; ไม่รวมการย้ายระบบจริง

## Required Inputs / Prerequisites

Server inventory, รายการ Application Owner, สิทธิ์อ่าน Configuration/Logs ตามที่ตกลง, ข้อมูลระบบเชื่อมต่อที่เกี่ยวข้อง

## Standard Delivery Activities

1. Kickoff และรวบรวม Server Inventory  (1 วัน)
2. วิเคราะห์ Application, Dependency และ Compatibility  (2 วัน)
3. กำหนด Target Platform, Baseline และ Migration Approach  (1 วัน)
4. จัดทำ Risk Register, Migration Waves และ Roadmap  (2 วัน)

## Deliverables

Server/Workload Inventory, Dependency & Risk Assessment, Migration Strategy และ Roadmap

## Acceptance Criteria

ส่งมอบ Inventory และ Dependency/Risk Assessment พร้อม Migration Roadmap และรายการที่ต้องยืนยันก่อนลงมือย้าย

## Reusable Delivery Assets

Inventory & Dependency Worksheet, Risk Register, Migration Wave Plan

## Assumptions & Exclusions

อาศัยข้อมูลจากทีม System/Application Owner; ไม่รวมการทดสอบย้ายระบบจริง

## Reuse Guidance

ก่อนใช้งานกับแต่ละองค์กร ให้ยืนยันจำนวนระบบและขอบเขตที่ต้องดำเนินการ, สิทธิ์เข้าถึง, ข้อกำหนดด้าน Security/Compliance, งานที่ขึ้นกับ Third Party, Change Window, ผู้รับผิดชอบ Validation และปรับ Effort ตาม Complexity จริง

งานที่อยู่นอก Scope ต้องระบุเป็น Additional Work Item ก่อนดำเนินการ
